## About

IT Support Specialist moving into **security operations**.

Day to day I handle 1st- and 2nd-line support, and 3rd-line cases when needed, for about 600 users and roughly 40 new tickets a day. Triage, troubleshooting under time pressure and clear documentation are my routine. I'm now building the security side of that skill set: studying for CompTIA Security+ and creating tools that give visibility into what is actually running on a network.

## Projects

| | |
|:--|:--|
| **[siec-ip](https://github.com/lu0i/siec-ip)**<br><sub>Python · Docker · GitHub Actions</sub> | Home network inventory and monitoring. Discovers every device on the LAN (ping sweep + ARP), tracks devices by MAC address with IP history, fingerprints 28 common services and flags devices that appeared in the last 24 hours, all in a searchable web dashboard. Single Python file using only the standard library; runs with Docker, systemd or a Proxmox LXC container, and a Windows `.exe` is built in CI. Includes a documented threat model in [`SECURITY.md`](https://github.com/lu0i/siec-ip/blob/main/SECURITY.md). |
| **AI SOC Agent**<br><sub>LLM · SIEM</sub> | Thesis project: an AI agent that assists analysts with SIEM alert triage. *In progress, not public yet.* |
| **Field Service App**<br><sub>Flutter · Dart · Supabase · PostgreSQL</sub> | Android app and web panel for an installation crew: photo documentation of every job and signed handover protocols. Access control enforced with PostgreSQL row-level security; 100+ automated tests. *Private client project, happy to walk through it in an interview.* |

Outside of that I design and build websites for local businesses at **[webartera.com](https://webartera.com)**.
